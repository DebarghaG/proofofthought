# ProofOfThought v1.0.1

This is the archived documentation entrypoint for the legacy `1.0.1` release line.

Use this version if you need:

- the pre-`2.0.0` public API shape
- the older `smt2`-first product story
- migration context for the removed JSON backend

For the new staged-major release, go to the latest docs:

<https://debarghaG.github.io/proofofthought/>

## Install v1.0.1

```bash
pip install "proofofthought==1.0.1"
```

## Main Differences From 2.0.0

- `2.0.0` makes the staged-SMT pipeline the core product architecture.
- `1.0.1` reflects the pre-major release API and docs structure.
- `2.0.0` removes the JSON backend from the public API.
